# RISE Repository

- Benchmark implementations live under `rise/<dataset>/`.
- For StateBench work, read `rise/statebench/README.md` and
  `rise/statebench/AGENTS.md` before running code.
- Do not move benchmark data out of its dataset directory or download external
  benchmark repositories when the selected package is self-contained.
- Keep API keys, private endpoints, logs, outputs, and virtual environments out
  of the repository.
